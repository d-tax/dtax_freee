freee 拡張ポータル

freee APIを活用した業務効率化ツール群

1. freee API 認証設定
静的サイト（GitHub Pages等）で運用するため、freeeアプリのアクセストークンを直接設定して接続します。
※ freeeデベロッパーポータルやAPIテストツール等で発行したアクセストークンを貼り付けてください。
2. 対象事業所の選択
利用する事業所を選択してください。選択は全ツールに反映されます。
3. 利用するアプリを選択
現在の選択事業所：
取引先台帳クリーニング
重複登録の探知や名寄せ統合を行います。
期日超過の未決済売掛金チェッカー
決済期日を過ぎた未回収の売掛取引をリストアップします。
ポチポチ手入力取引チェッカー
何度も手入力している取引を炙り出します。
取引の異常値・異常入力チェッカー
金額の桁間違いや税区分の矛盾などを検知します。
固定資産ワンタップスキャン
請求書から固定資産登録用の項目を自動抽出します。
